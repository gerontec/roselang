# What can be found through Rose

Counted in the shipped knowledge (`rose/std/`, build 2026-11-08); generated by `tools/stats.py`. Every count is a distinct card: one theorem, one plant species, one drug, one package. `rose.exists()` searches all of them.

**278 969 searchable cards**: 87 674 in the catalog, 189 932 mathlib statements, 1 363 Rosetta Code tasks (with 2 606 Python solutions). In addition 30 problem classes recognised by the structure of a task, and 1 251 units with Rose source (laws, formulas, constants, open problems) usable in `rosec` programs.

## Local only: effect → compound → organism (MariaDB)

Not part of the Python module. Built by `tools/build_effect_map.py` from the corpus (LOTUS, GRIN, drug cards) and `tools/import_chembl_effects.py` from a local ChEMBL copy, next to the DIAMOND tables (`blast_*`), into the tables `rose_effect`, `rose_compound`, `rose_organism`, `rose_compound_effect`, `rose_compound_organism` and the view `rose_v_effect_compound_organism`. Not shipped: rows from share-alike sources (ChEMBL) stay in the local database (CONCEPT.md P12).

46 932 organisms, 227 853 compounds, 543 682 compound-organism records.

## Not in the package

- all ~907 000 PyPI projects: release asset `pypi-2026-11` ([DATASET.md](pypi/DATASET.md))
- OEIS (> 400 000 sequences, CC BY-SA): corpus database only
- LOTUS natural products (CC BY 4.0): corpus database and the local effect map only
- ChEMBL (CC BY-SA): local MariaDB only, never exported
- the local NCBI nr for homology search: built by the user ([NR_BACKEND.md](bio/NR_BACKEND.md))
