# What can be found through Rose

Counted in the shipped knowledge (`rose/std/`, build 2026-11-08); generated by `tools/stats.py`. Every count is a distinct card: one theorem, one plant species, one drug, one package. `rose.exists()` searches all of them.

**268 747 searchable cards**: 77 452 in the catalog, 189 932 mathlib statements, 1 363 Rosetta Code tasks (with 2 606 Python solutions). In addition 30 problem classes recognised by the structure of a task, and 1 251 units with Rose source (laws, formulas, constants, open problems) usable in `rosec` programs.
