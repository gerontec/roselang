### fastapi-versioning

`pip install fastapi-versioning` · installs (wheel) · licence: MIT License · rank 14918 · last release 2021-08-24 · [PyPI](https://pypi.org/project/fastapi-versioning/)

<details><summary>README extract</summary>

api versioning for fastapi web applications

Example:
```python
from fastapi import FastAPI
from fastapi_versioning import VersionedFastAPI, version

app = FastAPI(title="My App")

@app.get("/greet")
@version(1, 0)
def greet_with_hello():
    return "Hello"

@app.get("/greet")
@version(1, 1)
def greet_with_hi():
    return "Hi"

app = VersionedFastAPI(app)
```
