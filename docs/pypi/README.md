# What the top PyPI packages are for

The 14,993 most-downloaded Python packages (last 30 days, [hugovk/top-pypi-packages](https://hugovk.dev/top-pypi-packages/), built 2026-11-08), grouped by their Trove topics: what each package is for, its licence, whether it installs on CPython 3.14 (Linux x86_64), and a short README extract cleaned for reading by people and LLMs (badges, images, HTML and link targets removed; intro, features, one example, section names).

- installable on CPython 3.14: 14,743 · with README extract: 13,084
- metadata as each project published it on PyPI; a README extract is the project's own text under its licence, and is left out for share-alike licences
- generated by `tools/pypi_overview.py`; machine-readable in `rose/std/catalog.jsonl` (cards `pypi:<name>`, kind `lib`) and via `rose.exists()`
- all ~900 000 PyPI projects in the same form: [DATASET.md](DATASET.md) (release assets)
