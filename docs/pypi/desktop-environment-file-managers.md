### Send2Trash

Send file to trash natively under Mac OS X, Windows and Linux

`pip install Send2Trash` · installs (wheel) · licence: BSD-3-Clause · rank 557 · last release 2026-01-14 · [PyPI](https://pypi.org/project/Send2Trash/) · [source](https://github.com/arsenetar/send2trash.git)

<details><summary>README extract</summary>

Send2Trash is a small package that sends files to the Trash (or Recycle Bin) *natively* and on
*all platforms*. On OS X, it uses native `FSMoveObjectToTrashSync` Cocoa calls or can use pyobjc
with NSFileManager. On Windows, it uses native `IFileOperation` call if on Vista or newer and
pywin32 is installed or falls back to `SHFileOperation` calls. ...
