### ufoLib2

ufoLib2 is a UFO font processing library.

`pip install ufoLib2` · installs (wheel) · licence: Apache-2.0 · rank 11852 · last release 2026-10-13 · [PyPI](https://pypi.org/project/ufoLib2/)

<details><summary>README extract</summary>

ufoLib2 is meant to be a thin representation of the Unified Font Object (UFO) version 3 data model, intended for programmatic manipulation and fast batch processing of UFOs.

It resembles the defcon library, but does without notifications, the layout engine and other support classes. ...
