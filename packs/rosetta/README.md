# roselang-rosetta

Rosetta Code tasks with their Python solutions as a knowledge pack for
[Rose](https://github.com/gerontec/roselang). Generated by `tools/export_pack.py rosetta`.

```python
import rose
t = rose.use("rc:Sieve_of_Eratosthenes")   # R205 warning: GFDL, share-alike
print(t.description)
print(t.code)                               # first solution that compiles as Python 3
```
