# roselang-mathlib

Theorem statements of [Lean mathlib4](https://github.com/leanprover-community/mathlib4) as a
knowledge pack for [Rose](https://github.com/gerontec/roselang): name, statement, docstring and
source link of every public theorem, level `proven` (checked by Lean). Generated by
`tools/export_pack.py mathlib`.

```python
import rose
rose.search("four squares theorem", k=3)
rose.get("mathlib:Nat.sum_four_squares")["statement"]
```
