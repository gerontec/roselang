# Licences of the built-in knowledge (`rose/std/`)

The files in this directory are generated by `tools/export_std.py` from the Rose corpus. The code
of Rose is MIT; every card in `catalog.jsonl` carries the SPDX id of its source in `license`.

| Source | Files | Licence | Attribution |
|---|---|---|---|
| Wikidata | `law.rose`, `math.rose`, `open.rose`, cards `source: wikidata` | CC0-1.0 | – (courtesy: Wikidata, https://www.wikidata.org) |
| CODATA 2022 (NIST) | `const/codata.rose`, cards `source: codata` | public domain (US government work) | CODATA Internationally Recommended 2022 Values of the Fundamental Physical Constants, NIST, https://physics.nist.gov/cuu/Constants/ |
| Gene Ontology | cards `source: gene_ontology` | CC-BY-4.0 | Gene Ontology Consortium, go-basic.obo (release in each card's source data), https://geneontology.org – "The Gene Ontology knowledgebase", Nucleic Acids Research |
| Rosalind | cards `source: rosalind` | titles and links only (reference) | https://rosalind.info |
| Rose core | cards `source: rose-core` | MIT | this project |
